# Student Grade Calculator

## 📌 Project Overview

The Student Grade Calculator is a Java-based program that calculates a student's total marks, average percentage, and grade based on the marks obtained in each subject.

This project was developed as part of the CODSOFT Java Development Internship.

## 🎯 Objectives

* Take marks obtained in each subject.
* Calculate the total marks.
* Calculate the average percentage.
* Assign a grade based on the average percentage.
* Display the final results clearly.
* Validate user input to prevent invalid marks.

## ✨ Features

* Accepts marks for multiple subjects.
* Accepts marks between 0 and 100.
* Rejects invalid marks.
* Prevents zero or negative number of subjects.
* Calculates total marks.
* Calculates average percentage.
* Assigns grades automatically.
* Displays formatted results.

## 📊 Grading System

| Average Percentage | Grade |
| ------------------ | ----- |
| 90–100%            | A+    |
| 80–89%             | A     |
| 70–79%             | B     |
| 60–69%             | C     |
| 50–59%             | D     |
| Below 50%          | F     |

## 🛠️ Technologies Used

* Java
* Java Scanner
* VS Code

## ▶️ How to Run

### 1. Compile the program

Open the terminal in the project folder and run:

```bash
javac StudentGradeCalculator.java
```

### 2. Run the program

```bash
java StudentGradeCalculator
```

### 3. Enter the required information

Enter the number of subjects and the marks obtained in each subject.

The program will display:

* Total marks
* Average percentage
* Grade
